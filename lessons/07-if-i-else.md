# Занятие 7. If и else

`if` и `else` — это выбор. Форму можно заполнить по-разному, и страница должна ответить по-разному: день выбран или нет, галочка стоит или снята, имя написано или поле пустое. Без этого выбора скрипт каждый раз делает одно и то же.

## 1. Теория

### Цепочка else if

`if` и `else` выбирают из двух веток. `else if` добавляет третью и следующие. Проверки идут сверху вниз. Выполняется первая, которая подошла, остальные пропускаются. `else` в конце — всё, что не совпало.

Кружки читаются так же, как галочка: у каждого свой класс и свой `checked`.

```js
const beginner = document.querySelector('.beginner');
const advanced = document.querySelector('.advanced');

if (beginner.checked) {
  answer.textContent = 'Группа для новичков, ' + nameField.value;
} else if (advanced.checked) {
  answer.textContent = 'Группа дальше, ' + nameField.value;
} else {
  answer.textContent = 'Сначала выбери группу';
}
```

Кружки не делают обязательными. Иначе пустую ветку `else` не увидеть: браузер остановит отправку раньше. Проверка по-прежнему стоит внутри `submit`, после `preventDefault`.

### Сравнение текста

У списка нет `checked` у пунктов. Берут весь список и смотрят `value`. С прошлого занятия: на странице виден текст пункта, в форму попадает `value`.

`===` значит «равно». Слева и справа одно и то же. `value` — это строка, поэтому справа тоже строка, в кавычках. Пустой первый пункт — пустая строка `''`.

```js
const day = document.querySelector('.day');

if (day.value === 'mon') {
  answer.textContent = 'Ждём в понедельник';
} else if (day.value === 'wed') {
  answer.textContent = 'Ждём в среду';
} else {
  answer.textContent = 'Выбери день';
}
```

То же сравнение ловит пустое имя, пока человек печатает. Событие `input` уже было. Поле пустое — одна фраза, без имени. В поле есть буквы — другая, имя берётся из `value`.

```js
nameField.addEventListener('input', function () {
  if (nameField.value === '') {
    answer.textContent = 'Напиши имя';
  } else {
    answer.textContent = 'Привет, ' + nameField.value;
  }
});
```

### Булевы операции

`checked` бывает `true` или `false`. Это булевы значения. Булевы операции соединяют такие проверки: «и», «или», «не».

`&&` — «и». Обе части должны быть верными. Если хотя бы одна неверна, ветка не выполняется.

```js
if (rules.checked && news.checked) {
  answer.textContent = 'Ждём тебя, ' + nameField.value;
}
```

Обе галочки стоят — фраза появляется. Снята любая из двух — эта ветка молчит.

`||` — «или». Хватает одной верной части. Если верны обе, ветка тоже выполняется.

```js
if (day.value === 'mon' || day.value === 'wed') {
  answer.textContent = 'Это будний день';
}
```

Сравнение пишут целиком с обеих сторон от `||`. Одно `day.value ===` на два слова не делится.

`!` — «не». Проверка переворачивается. `rules.checked` — галочка стоит. `!rules.checked` — галочка снята.

```js
if (!rules.checked) {
  answer.textContent = 'Сначала прочитай правила';
} else {
  answer.textContent = 'Ждём тебя в группе';
}
```

На шестом занятии первой проверяли поставленную галочку. Здесь первой проверяют снятую. Фразы те же, порядок веток другой.

`&&` и `||` в одной проверке пока не смешивают. Каждую пишут в своей ветке `if`.

## 2. Задания

### 1. Три группы

Папка `groups`.

Форма внутри карточки по центру, карточка уже окна. В форме обязательное имя, три кружка и кнопка «Отправить». Под кнопкой пустой абзац. Кружки не обязательные: форму можно отправить, не выбрав ни одного. Включён может быть только один.

Отправь форму с первым кружком. Страница не обновляется, в абзаце одна фраза, в ней имя из поля. Выбери второй и отправь снова. Фраза другая, имя то же. То же с третьим: своя фраза и то же имя. Сними выбор и отправь ещё раз. В абзаце четвёртая фраза, без имени.

Оставь имя пустым и нажми кнопку. Форма не отправляется, абзац не меняется.

## 3. Задание со звёздочкой

### 7. Один список, три темы ★

Папка `pick`.

Тексты придумай сам: подписи пунктов и три темы. Фразы из теории не бери. Имя указать можно. Фамилию, телефон, адрес и школу не пиши.

На странице список. Пустой первый пункт и три своих. Под списком три абзаца с темами. Их не видно: в HTML у каждого класс `hidden`, в CSS у этого класса `display: none`. Кнопки нет, форма не нужна.

Выбери первый пункт. Под списком появляется только его тема. Выбери второй. Первая тема скрывается, видна вторая. Выбери третий. Видна только третья. Верни пустой пункт. Тем снова не видно.

Смотри `value` списка через `else if`. У выбранной темы снимай `hidden` через `classList.remove`. Двум остальным ставь `hidden` обратно через `classList.add`. Для пустого пункта класс `hidden` ставь всем трём.

- [ ] Пустой пункт снова прячет все три

# Занятие 10. Массив

На девятом занятии у каждого игрока было своё имя: `firstPoints`, `secondPoints`, `thirdPoints`. Сумму собирали из этих имён. Сегодня несколько чисел лежат в одном массиве. У массива есть свои функции: добавить число в конец или в начало, снять его и проверить, есть ли такое значение внутри.

## 1. Теория

### Одно имя на несколько чисел

Массив — это список значений под одним именем. Значения пишут в квадратных скобках через запятую.

```js
const points = [0, 0, 0];
```

`const` здесь подходит: имя `points` остаётся при этом массиве. Меняют числа внутри, не само имя.

Номер пишут в других квадратных скобках. Счёт начинается с нуля. `points[0]` — первое число, `points[1]` — второе, `points[2]` — третье.

`length` говорит, сколько значений в массиве. Скобок у него нет: это не вызов функции.

```js
answer.textContent = points.length;
```

В абзаце будет `3`.

Номер за концом массива пустой. У трёх чисел нет номера `3`: длина как раз `3`, а номера кончаются на `2`. `points[3]` равен `undefined`. Если записать его в абзац, на странице появится это слово.

### Номер меняют

В номер можно записать новое число. Слева номер, справа новое значение.

```js
points[0] = points[0] + 3;
```

Берётся текущее первое число, к нему прибавляют `3`, результат кладут обратно в `points[0]`. Остальные номера на месте.

Сумму собирает функция. Плюсы пока пишут по номерам:

```js
function showSum() {
  answer.textContent = points[0] + points[1] + points[2];
}
```

Слушатель меняет свой номер и вызывает `showSum`. Чужой номер эта кнопка не трогает.

### Конец списка

Если в `textContent` записать сам массив, значения встанут в одну строку через запятую. Пробела после запятой нет. В коде пробел после запятой есть: так список удобнее читать. На странице его не будет.

```js
answer.textContent = points;
```

Массив `[0, 0, 0]` выглядит как `0,0,0`.

`push` добавляет значение в конец. Перед именем функции ставят точку и массив, к которому она относится. В скобках то, что добавляют. Скобки обязательны, как у любого вызова.

```js
points.push(4);
```

Было `[0, 0, 0]`, стало `[0, 0, 0, 4]`. `length` вырос на единицу. Новое число получает следующий номер.

`push` возвращает новую длину. В абзац её не кладут: длину по-прежнему читают через `length`, а список пишут отдельной строкой.

```js
points.push(4);
listText.textContent = points;
sizeText.textContent = points.length;
```

`pop` снимает последнее значение и возвращает его. В массиве этого значения больше нет.

```js
const last = points.pop();
```

`last` — снятое число. Его пишут в один абзац, список — в другой.

У пустого массива снимать нечего. `pop` вернёт `undefined`, и в абзаце окажется это слово. Перед вызовом проверяют длину, как раньше проверяли `count > 0`:

```js
if (points.length > 0) {
  lastText.textContent = points.pop();
}
listText.textContent = points;
```

На пустом массиве проверка не проходит, `pop` не вызывают.

### Начало списка

`unshift` добавляет значение в начало. Прежние номера сдвигаются: бывший `points[0]` становится `points[1]`.

```js
points.unshift(5);
```

Как и `push`, `unshift` возвращает новую длину. В абзац со списком пишут сам массив, не этот возврат. Иначе вместо чисел на странице останется одна длина.

`shift` снимает первое значение и возвращает его. Остальные подтягиваются к началу: бывший `points[1]` становится `points[0]`. У пустого массива та же проверка `length > 0`. Без неё `shift` тоже вернёт `undefined`.

### Есть ли такое значение

`includes` возвращает `true` или `false`. В скобках то, что ищут. `true` значит, что значение есть. `false` значит, что его нет.

```js
const menu = ['суп', 'чай', 'хлеб'];

if (menu.includes(dish.value)) {
  answer.textContent = 'Есть в меню';
} else {
  answer.textContent = 'Такого блюда нет';
}
```

Сравнение точное. `чай` и `Чай` для `includes` разные строки. Пустое поле — пустая строка, её в меню нет, срабатывает `else`.

Число и текст с цифрами тоже разные. В массиве `[4, 8]` нет строки `'4'`. Число из поля получают через `Number`, как на восьмом занятии: `numbers.includes(Number(field.value))`.

### 3. Снять последнее

Папка `pop`.

Карточка по центру. Своя тема. В массиве четыре своих числа, их видно в абзаце через запятую. Второй абзац — снятое число, сначала в нём `0`. Одна кнопка. Формы нет.

Кнопка снимает последнее число и пишет его во второй абзац. Список в первом абзаце становится короче. Снятие делает `pop`, и в абзац попадает то, что он вернул. На пустом массиве `pop` не вызывают.

### 7. Четыре товара ★

Папка `fair`.

Тему, названия и цены придумай сам. Числа `3`, `4`, `5`, `8` и подписи из теории не бери. Имя указать можно. Фамилию, телефон, адрес и школу не пиши.

Четыре товара. У каждого своё название, своя цена, абзац количества и кнопки «Ещё» и «Меньше». Ниже «Итого» и абзац с числом. Формы нет. В начале все количества `0`, итог `0`. Эти нули написаны в HTML.

Цены — один массив из четырёх чисел. Количества — второй массив. Кнопка меняет только свой номер. Ниже нуля количество не опускается. Итог возвращает функция:

```js
function totalCost() {
  return prices[0] * counts[0]
    + prices[1] * counts[1]
    + prices[2] * counts[2]
    + prices[3] * counts[3];
}
```

Одна функция пишет четыре абзаца и итог. Её вызывают все восемь кнопок, когда количество уже изменено. Слово «Итого» в скрипт не попадает.

Пока все количества нулевые, итог `0`. Прибавь один товар: итог станет равен его цене. Прибавь второй: итог станет суммой двух стоимостей.

### 8. Лента ★

Папка `tape`.

Тему и числа придумай сам. Числа `3`, `4`, `5`, `8` и слова из теории не бери. Имя указать можно. Фамилию, телефон, адрес и школу не пиши.

Один массив. В начале в нём два своих числа, они уже написаны в абзаце через запятую. Рядом абзац длины, в нём `2`. Поле «Число» и четыре кнопки: в конец, в начало, снять с конца, снять с начала. Ниже поле «Найти» и пустой абзац для фразы. Формы нет. Слова «Число», «Найти» и подпись длины в скрипт не попадают: скрипт пишет список, длину и фразу.

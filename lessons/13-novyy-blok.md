# Занятие 13. Новый блок

На двенадцатом занятии новый товар попадал в массив через `push`, а на странице его дописывали в одну строку: имя, пробел, цена и запятая. Абзацы были написаны в HTML заранее. Сегодня страница создаёт абзац сама. Сколько объектов в массиве, столько абзацев в списке.

## 1. Теория

### Один абзац

`document.createElement` создаёт блок. В скобках имя тега, в кавычках. Абзац получается из `'p'`. На странице его ещё нет: созданный блок лежит в переменной, пока его не вложат.

Пустой `div` уже стоит в HTML. `createElement` не собирает страницу, он создаёт один блок.

```html
<div class="list"></div>
<button class="add" type="button">Добавить</button>
```

```js
const list = document.querySelector('.list');
const add = document.querySelector('.add');

add.addEventListener('click', function () {
  const paragraph = document.createElement('p');
  paragraph.textContent = 'Сок';
  list.append(paragraph);
});
```

`textContent` пишет текст, как в уже готовый абзац. `append` кладёт абзац внутрь списка, в конец.

Первый клик показывает один абзац `Сок`. Второй клик не стирает его. `append` добавляет, а не заменяет, поэтому абзацев становится два, и в обоих написано `Сок`.

`const paragraph` на каждом клике называется заново. Старый абзац уже лежит в списке. Новое имя `paragraph` относится к новому абзацу.

### Строка из объекта

В абзац кладут свойства, не сам объект. Плюс склеивает имя, пробел и цену, как на двенадцатом занятии.

```js
const good = {
  name: 'Пирог',
  price: 36
};

add.addEventListener('click', function () {
  const paragraph = document.createElement('p');
  paragraph.textContent = good.name + ' ' + good.price;
  list.append(paragraph);
});
```

В абзаце будет `Пирог 36`. Если записать сам `good`, на странице будет `[object Object]`. Имя второй раз, отдельной строкой `'Пирог'`, в скрипте не пишут: его берёт `good.name`.

Очистки здесь нет. Второй клик добавит ещё один такой абзац, первый останется.

### Весь список

Несколько товаров лежат в массиве объектов. Список на странице собирает одна функция. Сначала она стирает всё, что уже лежит внутри `div`. Потом цикл создаёт абзац на каждый номер.

```js
const goods = [
  { name: 'Пирог', price: 36 },
  { name: 'Блин', price: 22 },
  { name: 'Кисель', price: 15 }
];

function show() {
  list.textContent = '';
  for (let i = 0; i < goods.length; i++) {
    const paragraph = document.createElement('p');
    paragraph.textContent = goods[i].name + ' ' + goods[i].price;
    list.append(paragraph);
  }
}

show();
```

`list.textContent = ''` пишет в `div` пустую строку. Вложенные абзацы пропадают. У самого абзаца пустая строка убрала бы только текст. Здесь пустеет список, и цикл наполняет его снова.

Вызов `show()` стоит в конце скрипта, без клика. Страница открывается, и три абзаца уже есть: `Пирог 36`, `Блин 22`, `Кисель 15`. В HTML внутри списка их нет.

Без очистки второй вызов `show` допишет три абзаца к старым. На странице их станет шесть, хотя в массиве по-прежнему три объекта. С очисткой старые пропадают, и цикл создаёт ровно три.

Созданные абзацы не ищут через `querySelectorAll`. Следующий `show` стирает их и создаёт новые. Искать их на странице по номеру больше не нужно: числа лежат в массиве.

### Новый товар

Кнопка по-прежнему одна, она написана в HTML. В массив она добавляет объект из двух полей, затем зовёт `show`.

```html
<label>
  Название
  <input class="title" type="text">
</label>
<label>
  Цена
  <input class="price" type="text">
</label>
<button class="add" type="button">Добавить</button>
```

```js
const title = document.querySelector('.title');
const price = document.querySelector('.price');

add.addEventListener('click', function () {
  goods.push({
    name: title.value,
    price: Number(price.value)
  });
  show();
});
```

`value` — текст. Цену переводят через `Number`, как на восьмом занятии. Пустое название даёт пустую строку. Пустая цена даёт `0`: `Number('')` равен `0`.

Если в полях `Компот` и `27`, после клика в массиве четыре объекта. `show` стирает три абзаца и создаёт четыре: `Пирог 36`, `Блин 22`, `Кисель 15`, `Компот 27`. Первые три не повторяются. Новый стоит в конце, потому что `push` кладёт объект в конец, а цикл идёт по порядку номеров.

### Кнопка в карточке

Кнопка у товара своя, и в HTML её нет. Её создают так же, как абзац. Тег кнопки — `'button'`.

У новой кнопки `type` равен `submit`. Ставят `button.type = 'button'`, как в HTML пишут `type="button"`. Так страница не обновится, если кнопка окажется в форме.

Карточке добавляют класс, чтобы её можно было оформить. `classList.add` уже был на шестом занятии.

```js
const goods = [
  { name: 'Пирог', price: 36, count: 0 },
  { name: 'Блин', price: 22, count: 0 },
  { name: 'Кисель', price: 15, count: 0 }
];

function show() {
  list.textContent = '';
  for (let i = 0; i < goods.length; i++) {
    const card = document.createElement('div');
    card.classList.add('product');

    const nameText = document.createElement('p');
    nameText.textContent = goods[i].name + ' ' + goods[i].count;

    const button = document.createElement('button');
    button.type = 'button';
    button.textContent = 'Ещё';
    button.addEventListener('click', function () {
      goods[i].count = goods[i].count + 1;
      show();
    });

    card.append(nameText);
    card.append(button);
    list.append(card);
  }
}

show();
```

`let` в заголовке `for` даёт каждому проходу свой `i`, как на одиннадцатом занятии. Первая кнопка держит номер `0` и меняет `goods[0]`. Вторая держит номер `1`. Чужой объект она не меняет.

Клик увеличивает `count` и снова вызывает `show`. Очистка снимает старые карточки вместе с их кнопками. Цикл создаёт карточки заново и вешает слушателей снова. В списке по-прежнему три карточки, не шесть. У первой в абзаце `Пирог 1`.

### Итог снаружи

Абзац с итогом в список не кладут. Очистка стирает только то, что внутри `list`. Итог стоит ниже, в HTML, и `show` его не создаёт.

```html
<div class="list"></div>
<button class="more" type="button">Ещё</button>
<p class="total">0</p>
```

`totalCost` считает, как на двенадцатом занятии. На каждом номере цена умножается на количество того же объекта.

```js
function totalCost(items) {
  let total = 0;
  for (let i = 0; i < items.length; i++) {
    total = total + items[i].price * items[i].count;
  }
  return total;
}
```

Для количеств `1`, `0` и `2` функция возвращает `36 * 1 + 22 * 0 + 15 * 2`, то есть `66`. Без `return` в абзаце будет `undefined`.

Одна кнопка в HTML прибавляет единицу каждому количеству и зовёт `show`. Внутри `show`, после цикла, итог пишут в готовый абзац.

```js
const total = document.querySelector('.total');

function show() {
  list.textContent = '';
  for (let i = 0; i < goods.length; i++) {
    const paragraph = document.createElement('p');
    paragraph.textContent = goods[i].name + ' ' + goods[i].count;
    list.append(paragraph);
  }
  total.textContent = totalCost(goods);
}

more.addEventListener('click', function () {
  for (let i = 0; i < goods.length; i++) {
    goods[i].count = goods[i].count + 1;
  }
  show();
});
```

Слово «Итого», если оно есть на странице, в скрипт не попадает. Его нет внутри `list`, поэтому очистка его не задевает.

Три игрока и одна цель. У каждого имя, шаг и очки. Очки в начале `0`. Шаги разные, каждый больше `1`. Ниже «Сумма» и `0`. Ниже «Осталось» и абзац: сначала в нём цель. Формы нет. Карточек игроков в HTML нет.

Игроки — один массив объектов, у каждого `name`, `points` и `step`. `show` очищает список и на каждого создаёт абзац и кнопку. Кнопка прибавляет шаг только своему объекту и снова вызывает `show`. Сумму считает цикл по `points`. Остаток считает `left`: если сумма уже больше цели, функция возвращает `0`.

```js
function left(goalValue, points) {
  if (points > goalValue) {
    return 0;
  }
  return goalValue - points;
}
```

Абзацы суммы и остатка стоят снаружи списка. Слова «Сумма» и «Осталось» в скрипт не попадают. `show` вызван в конце скрипта.

Нажми одну кнопку. Сумма равна шагу этого игрока, остаток меньше цели на этот шаг, карточек по-прежнему три. Когда сумма станет больше цели, остаток остаётся `0`, а очки растут дальше.

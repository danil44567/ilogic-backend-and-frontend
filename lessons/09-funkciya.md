# Занятие 9. Функция

На восьмом занятии одна и та же строка счёта стояла в каждом слушателе. Сегодня её записывают один раз, в функции, и вызывают. Два поля зовут одну сумму, две кнопки зовут одно обновление, функция возвращает стоимость.

## 1. Теория

### Одна функция на два поля

`function` даёт действию имя. Имя пишут сразу после `function`. В скобках пока пусто: функции ничего не передают. Тело в фигурных скобках — те же действия, что раньше стояли внутри слушателя.

```html
<label>
  Первое
  <input class="first" type="text" value="0">
</label>
<label>
  Второе
  <input class="second" type="text" value="0">
</label>
<p class="answer">0</p>
```

```js
const first = document.querySelector('.first');
const second = document.querySelector('.second');
const answer = document.querySelector('.answer');

function showSum() {
  answer.textContent = Number(first.value) + Number(second.value);
}

first.addEventListener('input', function () {
  showSum();
});

second.addEventListener('input', function () {
  showSum();
});
```

Слушатель на месте: `function ()` по-прежнему собирает действия на событие. `showSum` — отдельное имя. Его вызывают из слушателя.

Вызов — это имя и скобки: `showSum()`. Скобки обязательны. Без них функция не выполняется, и сумма в абзаце не меняется.

`showSum` видит `first`, `second` и `answer`: они объявлены в том же скрипте. Функцию пишут один раз, выше слушателей, не внутри них. Строка с `Number` остаётся только в функции. Нули по-прежнему написаны в HTML. До первой цифры функцию не вызывают.

### Обе кнопки

Строку, которая записывает число в абзац, тоже не копируют. Её забирает своя функция. Сначала меняют `count`, потом вызывают функцию. Вызов раньше времени запишет в абзац старое число.

```js
function showCount() {
  answer.textContent = count;
}

more.addEventListener('click', function () {
  count = count + 1;
  showCount();
});

less.addEventListener('click', function () {
  if (count > 0) {
    count = count - 1;
  }
  showCount();
});
```

Проверка `count > 0` остаётся в слушателе «Меньше». `showCount` только записывает текущее число. На нуле проверка не проходит, вызов всё равно стоит ниже: абзац обновляют на каждый клик.

### Функция возвращает число

`showSum` сама пишет в абзац. Другая функция абзац не трогает: она считает и отдаёт число.

Имена в скобках у `function` нужны одному вызову. Первое имя получает первое значение из вызова, второе — второе. Снаружи у этих имён нет.

```html
<p>Цена: 500</p>
<input class="quantity" type="text" value="1">
<p class="answer">500</p>
```

```js
const price = 500;
const quantity = document.querySelector('.quantity');
const answer = document.querySelector('.answer');

function cost(itemPrice, itemQuantity) {
  return itemPrice * itemQuantity;
}

quantity.addEventListener('input', function () {
  answer.textContent = cost(price, Number(quantity.value));
});
```

`return` отдаёт результат туда, где функция вызвана, и на этом функция останавливается. Вызов ставят туда, где нужно готовое число: справа от `=`.

`cost(price, Number(quantity.value))` подставляет числа по местам. `price` — это `500`, оно попадает в `itemPrice`. Количество из поля попадает в `itemQuantity`. В абзаце оказывается то, что вернул `return`.

Без `return` функция не отдаёт число. В абзаце появится слово `undefined`.

В абзаце заранее написана стоимость одного. До первой цифры функцию не вызывают. Пустое поле даёт ноль, поэтому и стоимость становится нулём. Число в `const price` и число в тексте «Цена: 500» — одно и то же.

### Две цены

Одну и ту же `cost` вызывают дважды. В каждый вызов передают свою цену и своё количество.

```html
<p>Взрослый: 100</p>
<label>
  Количество
  <input class="adult" type="text" value="0">
</label>
<p>Детский: 70</p>
<label>
  Количество
  <input class="child" type="text" value="0">
</label>
<p class="answer">0</p>
```

```js
const adultPrice = 100;
const childPrice = 70;
const adult = document.querySelector('.adult');
const child = document.querySelector('.child');
const answer = document.querySelector('.answer');

function cost(itemPrice, itemQuantity) {
  return itemPrice * itemQuantity;
}

function showTotal() {
  answer.textContent = cost(adultPrice, Number(adult.value)) + cost(childPrice, Number(child.value));
}

adult.addEventListener('input', function () {
  showTotal();
});

child.addEventListener('input', function () {
  showTotal();
});
```

Первый вызов `cost` считает взрослых, второй — детских. `showTotal` складывает два результата и пишет сумму в абзац. Слушатели сами не умножают: каждый только вызывает `showTotal`.

Цена попадает в вызов числом из `const`. Количество читают из поля и переводят через `Number`: `value` — это текст. Пока в обоих полях нули, итог ноль. Эти нули написаны в HTML.

## 3. Задания со звёздочкой

### 5. До цели ★

Папка `goal`.

Тему и числа придумай сам. Числа `500`, `100` и `70` не бери. Имя указать можно. Фамилию, телефон, адрес и школу не пиши.

Карточка по центру. Видна своя цель. Две кнопки со своими шагами: разные, оба больше `1`. Под кнопками очки, сначала `0`. Ниже «Осталось» и абзац: сначала в нём цель. В обоих абзацах только числа. Формы нет.

Одна функция прибавляет шаг и возвращает новые очки. Другая возвращает, сколько осталось. Если очки уже больше цели, она возвращает `0`. Третья пишет оба абзаца, её вызывают обе кнопки.

```js
function left(goalValue, points) {
  if (points > goalValue) {
    return 0;
  }
  return goalValue - points;
}
```

Слово «Осталось» в скрипт не попадает.

Нажми меньший шаг. Очки равны этому шагу, остаток уменьшился на него. Когда очки станут больше цели, остаток остаётся `0`, а очки растут дальше.

### 6. Три игрока до цели ★

Папка `relay`.

Тему, имена, шаги и цель придумай сам. Числа и подписи из теории не бери. Имя указать можно. Фамилию, телефон, адрес и школу не пиши.

Три игрока и одна цель. У каждого своё имя, свой шаг и одна кнопка. Шаги разные, каждый больше `1`. В начале у всех `0`. Ниже «Сумма» и число. Ниже «Осталось» и число: сначала это цель. Формы нет.

Кнопка прибавляет шаг только своему игроку. Сумму и остаток пишет `show`. Остаток считает `left`, как в прошлом задании.

```js
function show() {
  const sum = totalPoints();
  total.textContent = sum;
  leftText.textContent = left(goal, sum);
}
```

Так вызывают `show` все три кнопки, когда очки уже изменены:

```js
firstPoints = add(firstPoints, firstStep);
firstText.textContent = firstPoints;
show();
```

Пока очки нулевые, сумма `0`, остаток равен цели. Нажми одну кнопку: сумма станет шагом этого игрока. Когда сумма больше цели, остаток остаётся `0`. Слова «Сумма» и «Осталось» в скрипт не попадают.

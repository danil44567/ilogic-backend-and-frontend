# Занятие 6. Знакомство с JavaScript

На пятом занятии заполненная форма обновляла страницу, и текст пропадал. Сегодня страница сама меняет текст и оформление, пока человек с ней работает.

## 1. Теория

### Файл скрипта

JavaScript — третий файл рядом с `index.html` и `style.css`. Его называют `script.js`. Подключают в конце `body`, после всех тегов, с которыми скрипт будет работать:

```html
  <p class="answer"></p>
  <script src="script.js"></script>
</body>
```

Скрипт в `head` страницу ещё не видит: теги к этому моменту не собраны.

`const` сохраняет найденный элемент. `document.querySelector` ищет его по классу, как CSS. Точка перед именем обязательна.

```js
const form = document.querySelector('.signup');
const nameField = document.querySelector('.name');
const answer = document.querySelector('.answer');
```

Класс в скрипте и класс в HTML должны совпадать. У поля класс стоит на `input`, не на `label`: читать будем само поле.

### Отправка формы

`addEventListener` ждёт событие. У формы это `submit`: человек нажал кнопку отправки.

```js
form.addEventListener('submit', function (event) {
  event.preventDefault();
  answer.textContent = 'Заявка принята, ' + nameField.value;
});
```

`function (event)` — действия в момент события. `event` — само событие.

`preventDefault` отменяет обычный шаг браузера. Для формы это обновление страницы. Без этой строки фраза не успеет остаться: страница перезагрузится и абзац снова станет пустым.

`value` — текст, который сейчас написан в поле. `textContent` кладёт строку в абзац. Плюс склеивает два куска: готовую фразу и имя из поля.

`required` у поля никуда не делся. Пустое обязательное поле скрипт не запускает: браузер останавливает отправку раньше.

### Клик

У кнопки вне формы событие другое: `click`. Кнопка внутри формы без `type="button"` тоже отправит форму. Если отправка не нужна, тип пишут явно.

```html
<button class="paint" type="button">Покрасить</button>
```

```js
const paint = document.querySelector('.paint');
const card = document.querySelector('.card');

paint.addEventListener('click', function () {
  card.classList.add('active');
});
```

`classList.add` дописывает класс к тем, что уже есть в HTML. Цвет при этом задаёт CSS, не скрипт:

```css
.card.active {
  background-color: #d9f2e6;
}
```

`classList.remove` снимает класс.

### Пока человек печатает

Событие `input` происходит на каждом изменении поля: буква появилась или стёрлась.

```js
nameField.addEventListener('input', function () {
  answer.textContent = 'Привет, ' + nameField.value;
});
```

Форму для этого не отправляют. Поле пустое — в `value` пустая строка, и в фразе имени нет.

### Спрятанный блок

`display: none` убирает блок со страницы. Класс с этим свойством висит в HTML с самого начала.

```css
.hidden {
  display: none;
}
```

```html
<p class="message hidden">Ждём тебя в субботу.</p>
```

Скрипт снимает класс, и блок появляется. Текст уже написан в HTML, скрипт его не составляет:

```js
const message = document.querySelector('.message');

message.classList.remove('hidden');
```

Если блоков несколько, виден должен быть один. У выбранного класс `hidden` снимают. Двум остальным его ставят обратно через `classList.add`. Тогда `display: none` снова действует на них, и чужой текст пропадает.

### Два разных ответа

`if` выбирает одну ветку. `else` — другую, если проверка не прошла. У галочки есть `checked`: она равна `true`, когда галочка стоит, и `false`, когда снята.

```js
const rules = document.querySelector('.rules');

if (rules.checked) {
  answer.textContent = 'Ждём тебя в группе';
} else {
  answer.textContent = 'Сначала прочитай правила';
}
```

Эту проверку ставят внутрь `submit`, после `preventDefault`. Иначе страница обновится раньше, чем появится фраза.

## 2. Задания

Папку создавай как на прошлом занятии. Внутри **HTML File** `index`, **File** `style.css` и **File** `script.js`. Каркас тот же: `lang="ru"`, кодировка, свой `title`, подключённый `style.css`. У `body` убери внешний отступ. `script.js` подключи в конце `body`.

Кнопку оформляй как раньше: прямоугольник, светлый текст, без серой рамки браузера. Тему бери свою. Имя указать можно. Фамилию, телефон, адрес и школу не пиши. Фразы из теории не копируй.

### 1. Ответ на форму

Папка `answer`.

Форма внутри карточки по центру, карточка уже окна. В форме обязательное имя, обязательная почта, кнопка «Отправить» и пустой абзац под кнопкой.

Напиши имя и почту и нажми «Отправить». Страница не обновляется, поля не очищаются. В абзаце текст «Ждём тебя, » и сразу то имя, которое сейчас в поле.

В поле написано «Мира» — в абзаце «Ждём тебя, Мира». В поле «Лена» — «Ждём тебя, Лена». Других слов в абзаце нет.

Оставь имя пустым и нажми кнопку. Форма не отправляется, абзац остаётся пустым.

**Проверь:**

- [ ] В папке три файла, строка `script` в конце `body`
- [ ] После отправки страница не обновляется, поля на месте
- [ ] Для имени «Мира» абзац равен «Ждём тебя, Мира»
- [ ] Пустое имя не даёт отправить форму, абзац пустой

### 2. Кнопка меняет карточку

Папка `paint`.

На странице карточка с заголовком и кнопка. Формы нет. Кнопка не отправляет страницу.

Нажми кнопку один раз. У карточки меняется фон, цвет берётся из CSS. Заголовок на месте. Второй раз нажимать не нужно: фон остаётся новым.

**Проверь:**

- [ ] До клика фон карточки один, после клика другой
- [ ] Новый цвет записан в `style.css`, не в скрипте
- [ ] Страница не обновляется

### 3. Фраза во время набора

Папка `live`.

На странице поле для имени и абзац. Кнопки нет.

Печатай имя. Фраза в абзаце меняется на каждую букву, в ней есть то, что уже написано в поле. Сотри имя. Из фразы имя тоже пропадает.

**Проверь:**

- [ ] Фраза обновляется до нажатия Enter
- [ ] В фразе текущий текст поля
- [ ] Пустое поле оставляет фразу без имени

### 4. Спрятанный ответ

Папка `show`.

Собери страницу из двух видимых частей и одной спрятанной.

Видно сразу: заголовок «Секрет» и кнопка «Показать». Формы нет.

В HTML под кнопкой есть абзац с текстом «Занятие начнётся в шесть». У абзаца класс `hidden`, а в CSS у этого класса `display: none`. Из-за этого свойства абзаца не видно. Открой страницу: строки нет, есть только заголовок и кнопка.

Чтобы перекрыть `display: none`, в обработчике клика сними класс `hidden` методом `classList.remove`. Класса больше нет — свойство `display: none` к абзацу не применяется, и он снова виден. Другое свойство `display` в CSS для этого не нужно.

Нажми «Показать». Под кнопкой появляется ровно «Занятие начнётся в шесть». Кнопка и заголовок остаются. Повторное нажатие ничего не меняет.

Эти слова записаны в `index.html`. В `script.js` их нет.

**Проверь:**

- [ ] До клика на странице заголовок «Секрет» и кнопка «Показать», фразы нет
- [ ] После клика под кнопкой текст «Занятие начнётся в шесть»
- [ ] Эта фраза есть в `index.html` и её нет в `script.js`

### 5. Два ответа

Папка `choice`.

Форма в карточке: обязательное имя, галочка со своей подписью, кнопка и пустой абзац. Галочка не обязательная, её можно оставить пустой.

Отправь форму с галочкой. Страница не обновляется, в абзаце одна фраза. Сними галочку и отправь снова. В абзаце другая фраза. В обеих есть имя из поля.

**Проверь:**

- [ ] С галочкой и без неё фразы разные
- [ ] В каждой фразе имя из поля
- [ ] Страница не обновляется
- [ ] Пустое имя форму не отправляет

## 3. Задание со звёздочкой

### 6. Три темы ★

Папка `topics`.

Тексты придумай сам: подпись первой кнопки, подписи трёх кнопок выбора и три темы. Фразы из теории не бери. Имя указать можно. Фамилию, телефон, адрес и школу не пиши.

Сначала на странице свой абзац и одна кнопка. Блока с тремя кнопками не видно. Трёх тем не видно. Они лежат в HTML и спрятаны классом `hidden` с `display: none`.

Нажми первую кнопку. Появляется блок с тремя кнопками. Темы всё ещё скрыты.

Нажми одну из трёх. Под ними появляется только её тема. Нажми другую. Прошлая тема скрывается, видна новая. Нажми третью. Видна только третья тема. Две остальные в этот момент скрыты.

Чтобы чужая тема пропала, поставь ей класс `hidden` через `classList.add`. У выбранной темы этот класс сними через `classList.remove`.

**Проверь:**

- [ ] До клика видны только свой текст и одна кнопка
- [ ] После первой кнопки видны три кнопки, тем ещё нет
- [ ] После выбора видна ровно одна тема
- [ ] При выборе другой темы прошлая скрывается
- [ ] Тексты свои и записаны в HTML, не собраны в скрипте

# Занятие 12. Объект

На одиннадцатом занятии цена и количество одного товара лежали в двух массивах. Их связывал общий номер: `prices[i]` и `counts[i]`. Сегодня у товара одно имя. Внутри него название, цена и количество. Массив хранит такие товары. Цикл по-прежнему идёт по номерам и берёт `goods[i].price` и `goods[i].count`.

## 1. Теория

### Свойства одного имени

Объект собирает несколько значений под одним именем. Их пишут в фигурных скобках. У свойства есть имя и значение, между ними двоеточие. Соседние свойства разделяет запятая.

```js
const player = {
  name: 'Мира',
  points: 0,
  step: 6
};
```

`name` хранит строку, поэтому значение в кавычках. `points` и `step` — числа, кавычек у них нет.

`const` здесь подходит: имя `player` остаётся при этом объекте. Меняют свойства внутри, не само имя. Так на десятом занятии имя массива оставалось при списке, а числа внутри менялись.

Свойство читают через точку. Слева объект, справа имя свойства. Скобок нет: это не вызов функции.

```js
answer.textContent = player.points;
```

В абзаце будет `0`. `player.step` равен `6`, `player.name` равен `Мира`.

Чужого свойства в объекте нет. `player.score` равен `undefined`. Если записать его в абзац, на странице появится это слово.

### Свойство меняют

Слева свойство, справа новое значение.

```js
player.points = player.points + player.step;
```

Берётся текущее `points`, к нему прибавляют `step`, результат кладут обратно в `points`. `name` и `step` на месте.

Кнопка меняет очки и пишет их в абзац.

```js
add.addEventListener('click', function () {
  player.points = player.points + player.step;
  answer.textContent = player.points;
});
```

Первый клик пишет `6`. Второй пишет `12`. В абзаце число, не объект.

### Объект в абзаце

Если в `textContent` записать сам объект, свойства не разобрать.

```js
answer.textContent = player;
```

В абзаце будет `[object Object]`. Так выглядит любой объект: имя, очки и шаг на страницу не попадают.

Имя и очки пишут по отдельности. Плюс склеивает строку и число в одну строку, как на седьмом занятии. Пробел между ними — отдельная строка из одного пробела.

```js
answer.textContent = player.name + ' ' + player.points;
```

Для `Мира` и `0` в абзаце будет `Мира 0`. Когда `points` станет `6`, та же строка даст `Мира 6`. Имя берётся из объекта. Отдельной строкой `'Мира'` в скрипте его не пишут.

### Массив объектов

Несколько товаров лежат в одном массиве. Каждый товар — объект.

```js
const goods = [
  { name: 'Булка', price: 30, count: 0 },
  { name: 'Кефир', price: 24, count: 0 },
  { name: 'Сыр', price: 41, count: 0 }
];
```

Номер по-прежнему с нуля. `goods[0]` — первый объект. Его цена — `goods[0].price`, она равна `30`. Количество второго товара — `goods[1].count`, оно равно `0`.

Номер `0` берёт `goods[0].price` и `goods[0].count`. Номер `1` берёт цену и количество следующего товара. Второго массива нет: оба значения лежат в одном объекте.

`push` добавляет объект в конец, как на десятом занятии добавлял число.

```js
goods.push({ name: 'Чай', price: 18, count: 0 });
```

Было три товара, стал четвёртый. `length` вырос на единицу. Новый товар получает следующий номер. `goods[3].name` равен `Чай`.

Сам массив в абзац не кладут. Для трёх товаров на странице будет `[object Object],[object Object],[object Object]`. Строку собирает цикл. Перед первым товаром запятой нет, иначе список начнётся с неё. Перед каждым следующим ставится запятая без пробела, как у массива на десятом занятии. Между именем и ценой — пробел.

```js
function line(items) {
  let text = '';
  for (let i = 0; i < items.length; i++) {
    if (i > 0) {
      text = text + ',';
    }
    text = text + items[i].name + ' ' + items[i].price;
  }
  return text;
}
```

Для булки, кефира и сыра функция возвращает `Булка 30,Кефир 24,Сыр 41`. Вызов ставят туда, где нужна готовая строка.

```js
listText.textContent = line(goods);
```

### Итог одним списком

На одиннадцатом занятии итог собирали из двух массивов одной длины. Теперь функции передают один массив. На каждом номере цена умножается на количество того же объекта.

```js
function totalCost(items) {
  let total = 0;
  for (let i = 0; i < items.length; i++) {
    total = total + items[i].price * items[i].count;
  }
  return total;
}
```

Пока все количества `0`, функция возвращает `0`. Если количества станут `1`, `0` и `2`, внутри получится `30 * 1 + 24 * 0 + 41 * 2`, то есть `112`. Числа `3` в функции нет: длину цикл читает сам. Вызов ставят туда, где нужно готовое число.

```js
total.textContent = totalCost(goods);
```

Без `return` в абзаце будет `undefined`, как на девятом занятии.

Одинаковый класс пишут на каждом абзаце количества. Одна кнопка прибавляет единицу каждому. Слушатель один, внутри него цикл.

```html
<p class="count">0</p>
<p class="count">0</p>
<p class="count">0</p>
<button class="more" type="button">Ещё</button>
<p class="total">0</p>
```

```js
const texts = document.querySelectorAll('.count');
const more = document.querySelector('.more');
const total = document.querySelector('.total');

function show() {
  for (let i = 0; i < texts.length; i++) {
    texts[i].textContent = goods[i].count;
  }
  total.textContent = totalCost(goods);
}

more.addEventListener('click', function () {
  for (let i = 0; i < goods.length; i++) {
    goods[i].count = goods[i].count + 1;
  }
  show();
});
```

`querySelector` нашёл бы только первый абзац. `querySelectorAll` находит все, порядок как на странице.

### Своя кнопка

Если кнопка у каждого своя, у кнопок один класс. Игроки лежат в одном массиве объектов. Очки и шаг — свойства одного игрока, не два массива.

```js
const players = [
  { name: 'Мира', points: 0, step: 6 },
  { name: 'Глеб', points: 0, step: 9 }
];
```

```html
<button class="add" type="button">+6</button>
<button class="add" type="button">+9</button>
```

Цикл вешает `click` на каждую кнопку. `let` в заголовке даёт каждому проходу свой `i`, как на одиннадцатом занятии.

```js
const buttons = document.querySelectorAll('.add');

for (let i = 0; i < buttons.length; i++) {
  buttons[i].addEventListener('click', function () {
    players[i].points = players[i].points + players[i].step;
    show();
  });
}
```

Первая кнопка держит `players[0]` и прибавляет `6`. Вторая держит `players[1]` и прибавляет `9`. Чужой объект эта кнопка не меняет: другого номера у неё нет.

Сумму возвращает функция с циклом. Она складывает `points` объектов.

```js
function sum(items) {
  let total = 0;
  for (let i = 0; i < items.length; i++) {
    total = total + items[i].points;
  }
  return total;
}
```

`show` пишет очки в абзацы и вызывает `sum`. У цикла внутри `show` свой `i`.

### Самое дорогое

Самое дорогое имя ищут циклом, как самое большое число на одиннадцатом занятии. В `best` сначала кладут объект с номера `0`. Дальше сравнивают цены.

```js
function dearest(items) {
  let best = items[0];
  for (let i = 1; i < items.length; i++) {
    if (items[i].price > best.price) {
      best = items[i];
    }
  }
  return best;
}
```

Цикл начинают с `1`: номер `0` уже записан в `best`. Сравнивают `price`, а в `best` кладут весь объект. Знак `>` строгий. Равная цена место не занимает.

Функция возвращает объект. Его самого в абзац не пишут: получится `[object Object]`. Пишут имя.

```js
answer.textContent = dearest(goods).name;
```

Для булки, кефира и сыра в абзаце будет `Сыр`. Цена `41` больше `30` и `24`.

Тему, имена, шаги и цель придумай сам. Имена и числа из теории не бери. Имя указать можно. Фамилию, телефон, адрес и школу не пиши.

Три игрока и одна цель. У каждого имя, шаг, кнопка и абзац с `0`. Шаги разные, каждый больше `1`. Ниже «Сумма» и `0`. Ниже «Осталось» и абзац: сначала в нём цель. Формы нет.

Игроки — один массив объектов, у каждого `name`, `points` и `step`. Кнопки собирает `querySelectorAll`, слушателей вешает один цикл. Кнопка прибавляет шаг только своему объекту. Сумму считает цикл по `points`. Остаток считает `left`: если сумма уже больше цели, функция возвращает `0`.

```js
function left(goalValue, points) {
  if (points > goalValue) {
    return 0;
  }
  return goalValue - points;
}
```

`show` пишет три абзаца, сумму и остаток. Слова «Сумма» и «Осталось» в скрипт не попадают.

Нажми одну кнопку. Сумма равна шагу этого игрока, остаток меньше цели на этот шаг. Когда сумма станет больше цели, остаток остаётся `0`, а очки растут дальше.

# Занятие 11. Цикл

На десятом занятии сумму трёх номеров писали плюсами: `points[0] + points[1] + points[2]`. У четырёх товаров таких произведений было четыре, и у каждой кнопки был свой слушатель. Сегодня цикл проходит номера сам. Одни и те же строки считают сумму, пишут абзацы и вешают слушателей на кнопки. Сколько значений в массиве, цикл узнаёт по `length`.

## 1. Теория

### Сумма циклом

`for` повторяет тело. В заголовке три части, между ними точка с запятой.

```js
function sum(numbers) {
  let total = 0;
  for (let i = 0; i < numbers.length; i++) {
    total = total + numbers[i];
  }
  return total;
}
```

`let i = 0` задаёт номер, с которого начинают. Первый элемент по-прежнему нулевой.

`i < numbers.length` разрешает тело, пока номер меньше длины. Когда `i` сравнивается с длиной, такого номера уже нет, и цикл останавливается. Проверка строгая: номер, равный длине, лежит за концом.

`i++` после тела увеличивает номер на единицу. Это то же самое, что `i = i + 1`: взять `i` и прибавить единицу. Дальше проверка идёт снова.

`total = total + numbers[i]` прибавляет к сумме число с текущим номером.

Для `[4, 7, 2]` функция возвращает `13`. Внутри функции нет числа `3`: длину цикл читает сам. Четвёртое число в массиве тоже попадёт в сумму. Вызов ставят туда, где нужно готовое число.

```js
answer.textContent = sum(points);
```

Без `return` в абзаце будет `undefined`, как на девятом занятии.

### Два массива одной длины

Цена и количество с одним номером относятся к одному товару. Массивы одинаковой длины. Цикл один: на каждом номере цена умножается на своё количество.

```js
function totalCost(prices, counts) {
  let total = 0;
  for (let i = 0; i < prices.length; i++) {
    total = total + prices[i] * counts[i];
  }
  return total;
}
```

Номер `0` берёт `prices[0]` и `counts[0]`. Номер `1` берёт следующую пару. Отдельной строки на каждый товар больше нет.

### Все абзацы

Одинаковый класс пишут на каждом абзаце с очками. Точка перед классом обязательна.

```html
<p class="points">0</p>
<p class="points">0</p>
<p class="points">0</p>
<button class="all" type="button">Всем</button>
<p class="total">0</p>
```

`querySelector` нашёл бы только первый абзац. `querySelectorAll` находит все. Порядок как на странице: номер `0` — первый блок.

```js
const texts = document.querySelectorAll('.points');
const all = document.querySelector('.all');
const total = document.querySelector('.total');
```

У списка из `querySelectorAll` есть `length` и номера, цикл по ним такой же. `push` и `pop` к нему не применяют: `querySelectorAll` возвращает не массив.

Один цикл пишет каждое число в свой абзац. Сумму по-прежнему возвращает `sum`.

```js
function show() {
  for (let i = 0; i < texts.length; i++) {
    texts[i].textContent = points[i];
  }
  total.textContent = sum(points);
}
```

Одна кнопка может прибавить свой шаг каждому. Шаги лежат в отдельном массиве той же длины.

```js
all.addEventListener('click', function () {
  for (let i = 0; i < points.length; i++) {
    points[i] = points[i] + steps[i];
  }
  show();
});
```

Слушатель один. Внутри него цикл проходит всех.

### Слушатель на каждую кнопку

Если кнопка у каждого своя, им ставят один класс. На странице это разные кнопки, в скрипте один список.

```html
<p class="points">0</p>
<p class="points">0</p>
<button class="add" type="button">+3</button>
<button class="add" type="button">+5</button>
```

Цикл вешает `click` на каждую. Первая кнопка в списке — верхняя.

```js
const buttons = document.querySelectorAll('.add');

for (let i = 0; i < buttons.length; i++) {
  buttons[i].addEventListener('click', function () {
    points[i] = points[i] + steps[i];
    show();
  });
}
```

`let` в заголовке `for` даёт каждому проходу свой `i`. Первая кнопка держит номер `0` и шаг `steps[0]`. Вторая держит номер `1`. К концу цикла эти номера не сбиваются в один.

`show` вызывает свой цикл уже после изменения очков. У того цикла свой `i`, он заново идёт от нуля до длины и только пишет абзацы.

### Сколько подходят

Внутри тела можно поставить `if`. Функция считает, сколько чисел строго больше границы.

```js
function countAbove(numbers, limit) {
  let count = 0;
  for (let i = 0; i < numbers.length; i++) {
    if (numbers[i] > limit) {
      count = count + 1;
    }
  }
  return count;
}
```

Знак `>` строгий. Число, равное границе, в счёт не входит. Границу из поля переводят через `Number`: `value` — текст.

### Самое большое

Самое большое число тоже ищут циклом. В `best` сначала кладут номер `0`. Дальше сравнивают остальные.

```js
function biggest(numbers) {
  let best = numbers[0];
  for (let i = 1; i < numbers.length; i++) {
    if (numbers[i] > best) {
      best = numbers[i];
    }
  }
  return best;
}
```

Цикл начинают с `1`: номер `0` уже записан в `best`. Если очередное число больше, оно занимает место `best`.

# Занятие 8. Страница считает

На седьмом занятии страница выбирала фразу: другое имя, другой день, другая галочка. Сегодня она считает. Кнопка меняет число, два поля дают сумму, цена и количество дают стоимость.

## 1. Теория

### Кнопка меняет число

`const` и `let` дают имени значение. Имя пишут один раз, дальше к нему обращаются без этих слов.

`const` уже был на шестом занятии: так сохраняют элемент, найденный на странице. Имя остаётся при том же элементе. Текст внутри него менять можно. `textContent` записывает новую строку в абзац и не подменяет сам `const`.

`let` нужен, когда значение потом заменяют. Счётчик таким и будет: сначала в нём `0`, после клика уже другое число. Новое число записывают через `count = ...`. Если здесь поставить `const`, замена не выполнится: имя так и останется при нуле.

```html
<button class="more" type="button">Ещё</button>
<p class="answer">0</p>
```

```js
const more = document.querySelector('.more');
const answer = document.querySelector('.answer');
let count = 0;

more.addEventListener('click', function () {
  count = count + 1;
  answer.textContent = count;
});
```

`count = count + 1` берёт текущее число, прибавляет единицу и сохраняет результат обратно в `count`. Одна строка `count + 1` число не меняет: результат нужно записать обратно.

`textContent` записывает число в абзац. Ноль в HTML виден до первого клика: скрипт к этому моменту ещё не запускался.

Кнопка с `type="button"` страницу не отправляет. Форма для счётчика не нужна.

### Вычитание

Вторая кнопка уменьшает то же самое `count`. Второе `let` не заводят.

```js
const less = document.querySelector('.less');

less.addEventListener('click', function () {
  if (count > 0) {
    count = count - 1;
  }
  answer.textContent = count;
});
```

`count > 0` значит «число больше нуля». Пока это так, из числа вычитают единицу. На нуле проверка не проходит, и `count` остаётся нулём. Абзац обновляют на каждый клик.

### Сумма двух полей

`value` — это текст, даже когда в поле написаны цифры. Плюс склеивает такие тексты: `'2' + '3'` получается `'23'`.

`Number(...)` делает из текста число. `Number('2') + Number('3')` получается `5`. У пустого поля `Number('')` — это `0`.

Сумму считают на событии `input`. Оно приходит на каждую новую цифру. Слушатель нужен на каждом поле, иначе второе поле сумму не обновит.

```html
<label>
  Первое
  <input class="first" type="text" value="0">
</label>
<label>
  Второе
  <input class="second" type="text" value="0">
</label>
<p class="answer">0</p>
```

```js
const first = document.querySelector('.first');
const second = document.querySelector('.second');
const answer = document.querySelector('.answer');

first.addEventListener('input', function () {
  answer.textContent = Number(first.value) + Number(second.value);
});

second.addEventListener('input', function () {
  answer.textContent = Number(first.value) + Number(second.value);
});
```

Класс стоит на `input`, не на `label`. Строка с суммой в обоих слушателях одинаковая. Нули в полях и в абзаце написаны в HTML: до первой цифры скрипт ещё не считал.

### Цена и количество

`*` умножает. Цену, которая не меняется, пишут числом через `const`. Количество каждый раз читают из поля.

```html
<p>Цена: 200</p>
<input class="quantity" type="text" value="1">
<p class="answer">200</p>
```

```js
const price = 200;
const quantity = document.querySelector('.quantity');
const answer = document.querySelector('.answer');

quantity.addEventListener('input', function () {
  answer.textContent = price * Number(quantity.value);
});
```

Число в `const price` и число в тексте «Цена: 200» — одно и то же. В абзаце заранее написана стоимость одного. Пустое поле даёт ноль, поэтому и стоимость становится нулём.

### 4. Стоимость

Папка `price`.

Карточка по центру. На странице видна цена: своё число, не `200` из теории. Рядом поле количества, в нём с самого начала `1`. В абзаце уже написана стоимость одного: та же цена. Других слов в абзаце нет.

В скрипте цена записана тем же числом, что видно на странице. Пока количество меняют, абзац показывает цену, умноженную на количество. Напиши `2`: стоимость станет в два раза больше цены. Напиши `4`: в четыре раза больше. Сотри количество: в абзаце `0`.

## 3. Задание со звёздочкой

### 5. Три товара ★

Папка `shop`.

Тему, названия и цены придумай сам. Число `200` и подписи из теории не бери. Имя указать можно. Фамилию, телефон, адрес и школу не пиши.

На странице три товара. У каждого своё название, своя цена, абзац с количеством и две кнопки: «Ещё» и «Меньше». Под товарами написано «Итого», ниже отдельный абзац. В этом абзаце только число. Формы нет.

В начале у каждого товара количество `0`. Итог тоже `0`. Эти нули написаны в HTML.

«Ещё» и «Меньше» одного товара меняют только его количество. Чужие количества остаются на месте. Ниже нуля количество не опускается.

Итог — сумма трёх стоимостей. Цену товара умножают на его количество и три результата складывают:

```js
total.textContent = firstPrice * firstCount + secondPrice * secondCount + thirdPrice * thirdCount;
```

У каждого товара своё `let`, у каждой цены свой `const`. Числа в `const` те же, что написаны на странице. Строку с итогом ставят в конец каждого слушателя, когда количество уже изменено. Пока все количества нулевые, итог `0`. Прибавь один товар: итог станет равен его цене. Прибавь второй: итог станет суммой двух стоимостей.

Слово «Итого» в скрипт не попадает. Скрипт меняет только абзац с числом.
